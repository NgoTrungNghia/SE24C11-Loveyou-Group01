## 4. AI-Assisted Activities

AI tools were used for activities such as:

- **Documentation & Requirements:** Refining Use-Case Specifications and Model (Huy), tracking changes, and polishing the Weekly Report (Nghĩa).
- **Architecture Design:** Generating and structuring Mermaid code for System Context & Frontend (Huy), Container & Backend (Chiến), and Deployment (Nghĩa) architecture diagrams.
- **Feature Specification:** Using Spec Kit to generate formal specifications and task breakdowns for 2 new functional groups (Hoàng & Tấn).
- **Implementation:** Assisting with code-related questions and writing frontend/backend components using GitHub Copilot (Hoàng & Tấn).
- **Testing:** Generating Spec Kit test cases for the implemented features (Văn).

## 5. Human Review

All AI-generated content was reviewed by team members before being included in the project.

The team verified that:

- The generated information is relevant to the project and aligns with PA4 requirements.
- Architecture diagrams and deployment mappings exactly match the actual source code implementation.
- Code suggestions were thoroughly tested, reviewed, and integrated manually.
- Final architectural, documentation, and technical decisions were made by the project team.

## 6. Responsibility

AI tools were used strictly as assistance rather than as a replacement for the team's development, analysis, and decision-making process.

The project team maintains full ownership and is responsible for the final source code, documentation, architecture, and implementation.
