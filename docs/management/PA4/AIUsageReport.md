# 1. AI Usage Declaration

During PA4-2026, the LoveYou - Group 01 team used AI tools as supporting tools during software development, software architecture documentation, technical research, and documentation preparation.

AI tools were used to assist the team with understanding technical concepts, reviewing possible implementation approaches, improving documentation, and preparing software architecture materials.

The team members remained responsible for reviewing, validating, and making the final decisions regarding all AI-assisted outputs.

AI-generated content was not accepted blindly. The team reviewed the generated information and adapted it to the actual LoveYou project's source code, requirements, and implementation.

---

# 2. AI Tools Used

The main AI tool used during PA4-2026 was:

| AI Tool | Main Purpose |
|---|---|
| ChatGPT | Technical explanations, software architecture documentation, Markdown documentation, code-related assistance, and review support |

The team used AI as an assistant rather than as an autonomous development tool.

# 3. Purpose of AI Usage

AI assistance was used for the following activities:

## 3.1 Software Engineering Concepts

AI was used to help the team understand software engineering concepts related to PA4, including:

- Software architecture.
- C4 Model.
- System Context Diagram.
- Container Diagram.
- Component Diagram.
- Deployment Diagram.
- Scrum activities.
- Sprint planning.
- Sprint review.
- Spec-driven development.

The team used the explanations as learning and reference material before applying the concepts to the project.

---

## 3.2 Software Architecture Documentation

AI was used to assist with the preparation of architecture documentation.

The assistance included:

- Explaining the purpose of different C4 diagram levels.
- Suggesting appropriate documentation structures.
- Improving descriptions of system components.
- Reviewing relationships between system components.
- Assisting with Mermaid diagram syntax.
- Preparing Markdown documentation.

The final architecture documentation was reviewed against the actual project implementation.

---

## 3.3 Tech Stack Documentation

AI was used to assist in organizing and describing the technologies used by the LoveYou system.

The documentation covers areas such as:

- Frontend technologies.
- Backend technologies.
- Database technologies.
- Authentication.
- APIs.
- Supporting services.
- Development tools.

The team verified the technologies against the project source code before including them in the final documentation.

## 3.4 Code and Implementation Assistance

AI was used to support developers when they encountered questions related to implementation.

Examples of assistance include:

- Explaining code behavior.
- Explaining programming concepts.

- Helping identify potential causes of errors.

## 3.5 Documentation and English Writing

AI was used to improve the clarity and consistency of English documentation.

- Improving sentence structure.
