# 4. Definition of Done

A backlog item is considered completed when:

- Source code has been committed to GitHub.
- Documentation has been reviewed by another team member.
- Feature passes functional testing.
- No critical bugs remain.
- Coding standards are followed.
- The Product Owner accepts the deliverable.

# 5. Risks

| Risk | Impact | Mitigation |
| :--- | :--- | :--- |
| Merge conflicts during integration | Medium | Frequent pull requests and code reviews |
| Incomplete use case specifications | Medium | Internal document review before submission |
| UI prototype changes after review | Medium | Finalize requirements before implementation |
| API integration issues | High | Daily communication between frontend and backend developers |
| Schedule delay | High | Reassign tasks and prioritize critical backlog items |
