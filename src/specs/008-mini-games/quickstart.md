# Quickstart: 008 Mini-Games

## Testing Mini-Games

1. Log in with User A and User B in two separate browsers (or normal + incognito).
2. Open ChatPanel with each other on Dashboard.
3. User A clicks **🎮 Chơi game** in the top right of ChatPanel.
4. Select **🤔 Thích cái nào hơn?**.
5. User B receives a notification toast popup: "🎮 Lời mời game!". Click **Chấp nhận**.
6. Both users answer questions simultaneously. Watch progress sync in realtime and compatibility percentage calculated upon completion.
